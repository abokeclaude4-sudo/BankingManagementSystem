# Banking Management System

A Java-based Banking Management System developed using Object-Oriented Programming principles and modular application design.

## Features

- Create Bank Accounts
- View All Accounts
- Search Accounts
- Deposit Money
- Withdraw Money
- Delete Accounts
- Menu-Driven Console Interface

## Technologies Used

- Java
- Object-Oriented Programming (OOP)
- ArrayList Collections
- VS Code
- Git & GitHub

## Concepts Practiced

- Classes and Objects
- Constructors
- Encapsulation
- Collection Manipulation
- CRUD Operations
- Modular Programming
- Backend Logic
- User Input Handling
